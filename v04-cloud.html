Журнал интервалов

Ожидаем подключения.

Для теста используй только свой аккаунт. Не вводи реальные данные сотрудников. Параметры проекта сохраняются в этом браузере; вход Supabase также может сохранять сессию на устройстве. Не используй страницу на чужом компьютере.
